✓ MERGED · Google Production C++
Google cctz — timezone library
Problem: macOS + GCC 15 builds failing across Apple platforms. _XOPEN_SOURCE was lowering Darwin's __DARWIN_C_LEVEL, hiding C11 symbols GCC 15 requires.
Investigation → Solution: Traced the preprocessor chain, identified that __APPLE__ needed the same exclusion as FreeBSD/OpenBSD. Added !defined(__APPLE__) to the exclusion list. Verified on real macOS + GCC 15 CI.
Impact: Unblocked builds for all macOS + GCC 15 users across Google's internal and external CI.

Systems · C++17
KV Store — Redis-inspired
Challenge: Build a production-grade key-value store from scratch. Started single-threaded, profiled, then re-architected to thread-per-connection with mutex-protected shared state.
Client → TCP Listener → Worker Thread → Command Parser → Storage Engine → LRU Cache + AOF Persistence → Disk
What I learned: The 11% gap vs Redis isn't about C++ being slow — it's TCP connection reuse. My benchmark opens a new connection per request; Redis clients reuse them. That's where the time goes.
O(1) GET/SET/DEL via LRU eviction and AOF persistence.
